# 设计约束

本文件提炼自用户在设计讨论中的连续选择与修正。更新日期：2026-11-14。

## 已确认方向

### 品牌与产品

- 中文名为 **留频**，替换最初的「慢调」。英文沿用当前项目 README 的 **Stay Tuned**；项目目录为 `stay-tuned`。
- 产品以播客收听为核心视觉场景，延续当前项目已有的 RSS 播客与网络电台能力。
- 记忆点是**博朗 / Dieter Rams 风格的收音机**。不要使用黑胶、唱片、唱臂或唱盘作为主视觉。
- 品牌标识使用简洁的调谐刻度与橙红色竖向指针，保留与「留频」字标的清晰间距。

### 外观与主题

- 同时支持 **拟物 / 扁平** 两种外观，可以切换。
- 同时支持 **亮色 / 暗色** 两种主题；主题与外观独立，组成四种组合。
- **3D 彩蛋**：默认不加载 Three.js。只在拟物模式下连续长按播放键 5 秒后，按需加载并在原位置替换收音机；保留周围页面和当前播放状态，允许自由旋转、缩放及操作实体控件，不使用独立页面或弹窗。
- 拟物模式采用奶油白或炭灰机身、精密孔阵、实体推杆与按键，材质和阴影克制，具有可信的硬件结构。
- 上盖与前面板应体现同一种机身材质的色相关系，允许受光造成的明暗变化；不得因独立的去饱和 / 压暗滤镜出现一块中性灰上盖或明显贴片色差。
- 上盖后侧两角也应圆润，后沿到两侧斜边连续过渡，与前脸圆角形成统一的塑料机壳轮廓。
- 扁平模式使用相同控件和信息语义，以纯色与简洁线条表达。保留品牌、收音机识别和操作位置关系。
- 亮色以暖白、浅暖灰、深灰文字为主；暗色以温暖的炭灰和柔和浅色文字为主。橙红色用于主要操作与章节推杆指示线，灰绿色作为辅助色。

### 控件：双横向推杆

- **章节推杆与音量推杆均使用横向线性滑块，替换旋钮。** 需要兼顾鼠标和触控，不再依赖旋转手势或点击旋钮切换。
- 章节推杆位于上方，较醒目，滑块以橙色竖线指示当前位置；音量推杆位于下方，视觉较轻，使用灰绿色指示线。
- 两根推杆保留清晰的间距、轨道和固定刻度，避免混淆；拟物版采用浅内凹轨道与带轻微握纹的矩形滑块。
- 手机端也保留应用内音量推杆；此前只依赖系统音量的提案已被后续增加音量推杆的要求覆盖。
- **音量大小仅由音量滑块的位置表达。** 不在屏幕、机身或其他可见区域显示音量百分比、数字、条格、电平表等重复读数。
- 固定的扬声器图标与「音量」功能标签可以保留，它们标识控件用途，不是音量大小读数。
- 下方播放进度条继续用于连续时间定位，与章节推杆区分。不得把章节控件当作整集播放时间滑条。

### 屏幕：小型、真实、克制

- 使用较小的横向两行液晶显示窗，位于右侧控制区上方；尺寸和留白参照 `references/current/`。
- 拟物模式的视觉接近**未开背光的反射式单色 LCD**：低饱和灰绿基底、深灰绿色点阵字。不要恢复亮绿色发光字、强烈背光或大块深绿高亮屏。扁平模式保留屏内信息和位置，使用对应主题的纯色信息窗。
- 窗口具有细边框、轻微内凹、非常克制的玻璃反射。不要用层叠粗边框、夸张斜向高光或发光晕染。
- 屏幕只需显示播放状态、时间和当前章节，例如第一行小播放三角与 `18:42`，第二行 `02 专注与留白`。
- 字体大小与窗口协调，像真实点阵显示；不要用大号普通 UI 标题占满屏幕。
- 章节名称、时间、播放状态等**动态内容必须显示在收音机的小屏幕内**，不能像可变印刷字一样放在塑料或金属面板上。
- 机身只保留固定印字与刻度，如「章节」「音量」、品牌和实体按键图标。章节名称、变化的章节编号不作为永久机身丝印。
- 屏幕不显示任何音量信息，滑块位置已承担音量反馈。

### 桌面与手机编排

- 桌面端以左右双栏为主：左侧收音机，右侧节目与文字稿，下方统一播放控制。
- 手机端使用纵向单列：品牌与外观入口、节目信息、收音机、当前章节与文字稿预览、播放进度及控制。
- 手机端保留章节和完整文字稿的展开入口；主要播放操作放在下方，避免直接缩小桌面双栏。
- 各外观保留相同功能与稳定的位置关系。手机与桌面可以分别编排，但控件语义保持一致。
- 示例节目、标题与文字稿只是排版样例，不是硬编码产品内容。

## 实现建议（与用户明确约束区分）

以下是设计过程中提出的落地建议，不应被误记为用户单独确认的全部行为规格：

- 章节推杆拖动时预览目标章节，释放后吸附并切换；音量推杆连续调节。
- 切换拟物 / 扁平或亮色 / 暗色时保持当前节目、播放状态、进度、队列和文字稿位置。
- 鼠标、触控及键盘均能操作滑块，拖动手机推杆时避免与页面滚动冲突；实际触控区域应大于细小的可见轨道。
- 可使用原生滑块或等价无障碍语义。用户不希望显示可见音量数值，并不禁止为辅助技术提供必要的数值语义。
- 小 LCD 是硬件视觉元素，常规 UI 中的节目标题、章节摘要和文字稿仍应保持易读，避免把所有内容塞进小屏。
- 电台模式继续遵守项目已有的直播语义；不能把无回放的直播伪装成可任意拖动的播客时间轴。相关信息同样遵循动态显示与固定印字的区分。

  - `src/components/hardware/Fader.tsx`：横向双推杆，章节推杆支持拖动预览、释放吸附，音量推杆连续调节；触控及键盘可用，音量数值仅提供给辅助技术。
  - `src/components/hardware/Lcd.tsx`：两行反射式小屏，播放状态 / 时间 / 当前章节；电台模式显示 LIVE 与电台名，不显示任何音量信息。
  - `src/components/Receiver.tsx`：奶油色 / 炭灰收音机机身、精密孔阵、固定印字、LCD 和实体按键；章节名称等动态内容只进入 LCD 与机身外的「当前章节」行。
  - `src/components/CurrentChapterRow.tsx`、`ChaptersSheet.tsx`：桌面与手机共用的当前章节摘要和章节 / 电台选择抽屉。
  - 桌面端外观切换收进右上角「外观设置」菜单；手机端保留直接的拟物 / 扁平与浅色 / 深色入口。四种组合共用相同控件语义。
  - 旧的旋钮、`ChapterTuner`、音量滑条及音量数字读数已移除。
- 拟物上盖与前面板共用相同尺寸、相同坐标的材质渐变场，覆盖亮色、暗色、桌面和手机。上盖仅增加轻微受光高光，不再使用独立图片切片或单独的滤色；原 `public/textures/receiver-lid-light.png` 保留作历史资产，不参与当前运行时绘制。
- 上盖位于圆角前面板后方，斜边顺着前脸圆角收进机身；前面板起点与圆角尺寸共用几何变量，避免上盖底边横切前脸、两端突出尖角。
- 上盖使用 `public/shapes/receiver-top.svg` 的矢量遮罩：后侧两角为与后沿、斜边相切的曲线，随机身同比缩放；遮罩只定义轮廓，材质仍与前面板共用。
- 2026-11-14 拟物细节修正：统一塑料包边、孔阵的孔沿反光、机身接触阴影与脚垫；推杆使用无进度填充的实体凹槽、握纹矩形帽和一致的轨道端点；小 LCD 使用本地 Fusion Pixel 中文点阵字体。暗色保持深色孔洞，扁平模式移除材质和阴影。当前实现截图见 `docs/screenshots/hardware-refinement-2026-11-14/`，校验记录见项目根目录 `design-qa.md`。
- 深色扁平修正：使用低对比的深色孔阵，避免反转为亮白点阵；液晶采用深灰绿纯色底与浅字，滑块、轨道和按钮统一到炭灰 / 灰绿 / 橙色配色，取消该模式的环境光晕、纹理和卡片投影。该配色仅作用于深色扁平，拟物及亮色外观保持独立。
- 当前实现截图已更新至 `docs/screenshots/`；它们仍只是实现记录，不是设计基准。

- 设计参考图本身未修改；后续再有视觉差异时，仍以用户最新要求 > 本约束 > `references/current/` > exploration 的顺序判断。
